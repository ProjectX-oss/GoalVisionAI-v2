# Model Recalibration Recommendations

Recalibration evidence is driven by ECE/MCE deterioration, sustained probability bias, extreme-probability failures, and artifact or market-level calibration drift. Outcomes are not-required, monitor, recommended, or urgent review.

Every recommendation specifies a minimum independent validation sample. The foundation does not fit, register, activate, or silently substitute a calibration artifact. Any future recalibration must use a reviewed temporal boundary and pass the existing calibration-quality foundation.
