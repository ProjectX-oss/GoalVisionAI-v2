# Lab Operator Console Operations

1. Stop writers, copy the isolated database, and record its SHA-256 hash.
2. Run `config-check`; require `127.0.0.1`, read-only, scheduler and automatic
   publication false, and an allowed database path.
3. Review Overview, Readiness, Unresolved, Incidents and Health before chains.
4. Inspect odds → analysis → observation → preview → review → result →
   settlement. Never edit immutable evidence.
5. Restart with `--enable-actions` only for an approved operation. Supply a real
   operator identifier and exact confirmation; return to read-only afterward.
6. Provider actions remain blocked until a separately reviewed bounded executor
   is injected after Pro activation. Navigation must make zero network calls.
7. Send readiness is inspection-only here. Use no real Telegram transport.
8. Generate, reproduce or compare reports explicitly. Create exports only under
   an allowed local root, and retain losses, voids and blockers.
9. Incident acknowledgement never repairs or validates corruption.
10. Stop with Ctrl+C, check FK/health/action counts and compare database hashes.

Stop on external binding, secret output, page-request networking, Telegram
construction, failed foreign keys, missing immutable triggers, unexpected hash
changes or any Official/bankroll mutation.
