# First LAB Post-Match Review

Run `python -m app.lab_launch_readiness post-match-review --database <LAB_DB> --observation-id <ID> --output human`. The read-only default inspects observation, imported result, and deterministic settlement. Missing evidence returns an incomplete review.

Provider result fetching remains a separate explicit current-odds command. After validated capture and settlement, the operator refreshes monitoring, governance, weekly reporting, and the result-message preview using their existing explicit commands. No result is automatically published, and losses remain immutable history.
