# Model Rollback Review

Rollback review evidence links persistent degradation, severe drift, integrity-critical incidents, and generation comparisons to the existing controlled activation/rollback foundation. Outcomes are `ROLLBACK_NOT_REQUIRED`, `ROLLBACK_MONITOR`, `ROLLBACK_REVIEW_REQUIRED`, or urgent review.

A recommendation is not an execution authorization. It never changes the champion registry or runtime resolver. A future operator must inspect immutable activation history, artifact compatibility, shadow evidence, affected scopes, and current incidents, then use the separately reviewed two-stage rollback workflow if explicitly approved.
